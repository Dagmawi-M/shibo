## Get the compiler

Shibo runs your real sketch, so it needs the Arduino compiler (`arduino-cli`).

- **Already have it?** Shibo finds it by itself: on your PATH, in the usual install folders, or inside the Arduino IDE.
- **Do not have it?** Press **Check Setup** and pick the compiler. Shibo downloads it and the Arduino board package (about 80 MB, one time) and checks the download before using it.
- After that, everything works offline.

You can run **Shibo: Check Setup** at any time to see what is installed.
